## 3. 题目库说明

### 3.1 16 型版（20 道）

- **4 个维度**：决策依据（V/M）、持仓周期（L/S）、决策方式（I/F）、风险态度（A/C）
- **每题 4 选项**，**同测 2-3 维度**（避免"哪个选项是正确人格"的作弊）
- **评分**：每选项对 4 维度打分（+1 / 0）→ 累加 → 每维度高分极胜出 → 拼成 4 字母代码
- **16 人格**：VLIA / VLIF / VLCA / VLCF / VSIA / VSIF / VSCA / VSCF / MLIA / MLIF / MLCA / MLCF / MSIA / MSIF / MSCA / MSCF

### 3.2 段位版（10 道）

- **3 维评估**：投资成熟度 / 决策理性度 / AI 利用度
- **每题 4 选项**，分值 0/1/2/3（A=0 → D=3）
- **总分**：累加 0-30 → 百分制 `score = raw × 100 / 30` → 映射 5 段位
- **5 段位**：小韭菜（I）→ 青铜（II）→ 白银（III）→ 黄金（IV）→ 钻石（V）
- **超越比例**（MVP 预定义）：0% / 30% / 60% / 85% / 95%（v2 接入真实数据后动态计算）

### 3.3 题目库完整度

| 版本 | 题目数 | 期望 | 4 选项完整 | 状态 |
|---|---|---|---|---|
| 16 型 | 20 | 20 | 20/20 | ✓ |
| 段位 | 10 | 10 | 10/10 | ✓ |

## 4. 分享码规则

### 4.1 短码格式

- **16 型版**：`{4 字母代码}-{4 位 hash}` —— 示例：`VLIA-A1B2` / `MSIF-9K3P`
- **段位版**：`{罗马数字}-{4 位 hash}` —— 示例：`III-A1B2`（白银）/ `V-9K3P`（钻石）

### 4.2 4 位 hash 算法

```
输入：人格代码 + 段位 + 用户答题时间戳
算法：FNV-1a 双 hash（h1 × 0x01000193 + h2 × 0x85ebca6b）→ BigInt 拼接 → base62 取前 4 字符
alphabet：0-9, a-z, A-Z（62 字符）
```

**为什么不用 MD5？** 4 位 hash 长度下，MD5 取前 4 字符会出现 0-9 + a-f，**视觉上太"专业代码"**；base62 看着像"用户短码"，更适合朋友圈复制粘贴。

**已通过测试**：
- ✓ 长度 4
- ✓ alphabet 严格 0-9a-zA-Z
- ✓ 稳定（相同输入 → 相同输出）
- ✓ 区分度高（不同输入 → 不同输出）
- ✓ shareCode 格式正则 `^[A-Z]{1,4}-[0-9a-zA-Z]{4}$` 全通过

### 4.3 分享链接

```
{页面地址}?code={shareCode}
示例：file:///D:/xxx/gougou_test_16.html?code=VLIA-A1B2
```

**v1 落地页逻辑**（本地版）：`?code=xxx` 作为 URL 参数显示，**v1.1 + 真实部署**后可改成从 URL 解析 code + 调后端查"这是谁的人格"（用于"看朋友的结果"分享场景）。

## 5. 海报生成（html2canvas 客户端截图）

### 5.1 触发

- 结果页点击「生成海报」按钮
- 内置 `html2canvas@1.4.1` CDN 客户端截取指定 DOM 节点
- 输出 PNG，自动触发浏览器下载

### 5.2 海报设计

- 尺寸：1080 × 1920 px（适合朋友圈分享）
- 配色：渐变蓝紫 `#667eea → #764ba2` + 金色 `#f6d365` 强调
- 元素：头像占位 + 人格名 / 段位名 + 画像 + 3 工具 + 分享码 + 合规免责

### 5.3 文件命名

- 16 型：`股格_{代码}_{hash}.png` —— 例：`股格_VLIA_A1B2.png`
- 段位：`股格段位_{罗马}_{hash}.png` —— 例：`股格段位_V_9K3P.png`

## 7. 如何用本测试获客（结合课程定位 + 5 方评审洞察）

> **核心商业逻辑**：股格测试是"用户认知入口 + 课程入口引导器"——**测出来给一个结果 + 一份"你下一步应该学什么"的建议**——让用户从"测一测玩玩"变成"我要学这门课"。

### 7.1 获客漏斗（4 步）

```
[1] 朋友圈 / 公众号 / 抖音 → 看到测试入口
   ↓
[2] 完成测试（5 分钟）→ 拿到人格 / 段位
   ↓
[3] 看结果页"3 个 AI 工具" + "1 套策略提醒"
   ↓  （这是 99% 市面投资测试没做的"落地闭环"）
[4] 点"分享给朋友" / "生成海报" → 二次传播
   ↓
[5] 课程 CTA：「想系统学 AI 投资？点这里」
```

### 7.2 课程入口映射（5 方评审共识）

| 测试结果 | 课程模块 | 卖点话术 |
|---|---|---|
| 价投梭哈哥（VLIA） | 3.1 + 4.2 | "你已经有选股眼光，缺的是回测验证" |
| 涨停敢死队（MSIA） | 1.1 + 4.1 | "你节奏快，但缺 SOP，AI 帮你写 SOP" |
| 群消息小韭菜（MSIF） | 1.4 + 5.2 | "AI 帮你过滤噪音，识别 3 类信号" |
| 佛系老法师（VLIF） | 6.1 + 6.2 | "买完就忘？AI 帮你做月度体检" |
| 价值深耕派（VLCA） | 3.2 + 3.3 | "你已经是机构思维，缺的是多市场覆盖" |
| 纪律研究员（VSCF） | 4.1 + 4.3 | "你的研究已经够硬，差的是仓位算法" |
| 任何段位 | 全 6 模块 | "先学 X 模块，再补 Y 模块" |

### 7.3 5 方评审洞察（如何让测试"上头 + 落地"）

| 评审方 | 关键洞察 | 落地动作 |
|---|---|---|
| **research-team** | 散户最缺的不是工具，是"认知自己"——测试要先解决"我是谁" | 16 型版 MBTI 同款（4 字母 + 人格名）+ 口语化中文名 |
| **trader** | 散户最怕"我战胜了 XX%"的攀比感——段位版必须给"超越比例" | 段位版同花顺同款（5 段位 + 超越比例）|
| **buy-side-council** | 合规是底线——必须有"教育 / 娱乐用途"底注 | 海报 + 结果页 + 分享文案 3 处固定显示 |
| **retail-panel** | 散户分享动力 = "上头 + 攀比 + 落地"——3 件事缺一不可 | 4 字母代码 + 超越比例 + 3 工具推荐 = 3 合一 |
| **ai-pm** | 99% 投资测试"测完就完了"——必须有"AI 工具 + 策略"落地 | 每型 3 AI 工具 + 1 套策略提醒（基于 v2 附录 B 工具组合） |

### 7.4 上线后 1 周观察指标（数据驱动迭代）

| 指标 | 目标 | 含义 |
|---|---|---|
| 完成率 | ≥ 60% | 打开测试 → 完成全部题目 |
| 分享率 | ≥ 25% | 完成测试 → 点击分享 / 生成海报 |
| 二次访问率 | ≥ 15% | 完成测试 → 7 天内再次访问 |
| 平均测试时长 | 16 型 ≤ 5 分钟 / 段位 ≤ 3 分钟 | 超时可能题目太难 |
| 人格分布 | 16 型分布相对均匀 / 段位正态分布 | 严重偏态说明题目设计有问题 |
