## 这门课卖什么（一句话总结）

> **让一个完全没金融背景的普通散户，用 AI 工具把"凭感觉亏钱"变成"有纪律地少亏多赚"**——6 个模块 + 18 个小节 + 课前 0 基础开箱 + 2 份附录（研究底料速查卡 + 工具组合包），从扫盲到工具、从选股到复盘，全程实操可落地，学完当天就能用。

**卖课话术（50-100 字版）**：面向"会用 AI 但不会用 AI 投资"的散户，把市面 90% 的"AI 选股噱头课"换成"AI 防亏 + 提效"工具箱。6 模块 18 小节 + 课前 0 基础开箱：教 5 大坑避雷、3 款 AI 工具上手（i 问财 + Kimi + 通义）、5 维度个股梳理、回测 5 大坑、4 类情绪陷阱、4 步复盘官。全程实操 + 国产平替 + 4 套 prompt 直接 copy——学完当天能用，让散户"少亏多赚"。

## 面试授课小节推荐

> **v2 模块 2.2《让 AI 5 分钟速读一份财报 / 研报》**——零售双视角都给 ⭐⭐⭐⭐⭐，演示冲击极强，不踩合规线，国产平替支持，闭环教学。详见 `授课设计.md`。

**为什么是它（最有卖课爆点）**：
- 韭菜痛点："我看研报经常看睡着" 
- 老司机痛点："省下的时间就是钱"
- 演示效果：200 页 PDF → 5 分钟出 4 块摘要
- 闭环：演示"5 分钟读年报"+"10 分钟跨文档对比"+"AI 幻觉反例"+"4 招识别"——12 分钟一堂课

**教学目标**（3 条）：
1. **能**用 Kimi / 通义 / Claude 上传年报，1 段 prompt 5 分钟拿 4 块摘要
2. **能**用"AI 幻觉识别 4 招"判断 AI 输出是否可信
3. **能**在自己的真实投资场景中复用这套动作（10 分钟完成"1 年报 + 1 研报"对比速读）

**教学流程**（12 分钟）：
- 开场导入（1.5 分钟）——反常识数字抓住注意力
- 核心讲解（3 分钟）——3×3 矩阵 + 3 步流程 + 4 招识别
- 案例实操（6.5 分钟）——3 个真实场景：年报速读 + 跨文档对比 + AI 幻觉反例
- 总结收尾（1 分钟）——3 句话 + 1 个作业 + 1 句合规免责

## 股格测试（16 型版 · 2026-06-07 v1 → 2026-06-08 v1.3）

> **作为「AI 散户投资课程」的获客入口 + 学员自评工具**——单页 vanilla JS（无后端），4 维对极字母（V/M · L/S · I/F · A/C）严格 2^4 = 16 组合，每位置字母在对应维度字母集内。

### 一句话定位

**"像测 MBTI 一样测你的投资人格"**——5 分钟 20 题 → 16 型 4 字母代码 → 3 个 AI 工具 + 1 套策略提醒。

### 交付物

| 文件 | 说明 | 状态 |
|---|---|---|
| `股格测试/gougou_test_16.html` | 16 型测试交互页（20 题 · 4 维评分 · 16 人格结果页 · 海报生成） | **v1.3 已交付** |
| `股格测试/ggti_16_types.html` | 16 型参考页（面试速查 · 16 张卡 · 单页） | **v1.3 已交付** |
| `股格测试/README.md` | 完整使用说明 + 获客小贴士 | **已交付** |

### 核心功能（16 型版）

- **测试流程**：欢迎页 → 题目（4 选项 / 进度条 / 上一题下一题）→ 结果页
- **结果展示**：4 字母代码 + 16 人格名 + 1 句画像 + 3 特征 + 3 AI 工具卡片 + 1 套策略提醒
- **4 维 SVG 雷达图**：V/M · L/S · I/F · A/C 各轴 0-100 分
- **分享机制**：4 字母代码 + 4 位 base62 hash = `VLIA-A1B2` 格式 + `?code=xxx` 链接 + 复制到剪贴板
- **海报生成**：html2canvas@1.4.1 CDN 客户端截图 → 1080×1920 PNG 下载
- **本地存储**：localStorage 存"我的结果"，下次访问直接显示
- **响应式**：移动端 ≤ 768px 单列 + 触摸 ≥ 48px
- **合规底线**：3 处固定显示「教育 / 娱乐用途，不构成投资建议」
- **v2 占位**：HTML 底部含"v2 上线后即可用语音回答"小字 + disabled 按钮
